# Task 5

In this task, we use a dictionary to simulate a simple database of river
names. Each key in this dictionary is the name of a town or city, each
associated value is the name of the major river that runs through that town
or city.

This dictionary can therefore be used to look up a river name, given the
name of its town or city.

1. Examine `task5.py`, then run the program.

2. Under the relevant comment, add code that introduces two new key-value
   pairs into the dictionary. For example, you could use "York" as the
   one of the keys, and "Ouse" as the associated value.

   **Note: don't add these new key-values pairs to the initial definition
   of the dictionary!**

   After modifying dictionary contents, add a print statement to print out
   the dictionary, then run the program again.

3. Under the relevant comment, add a line that prints out the keys of
   the dictionary, then run the program again.

   **Note: do this with a single line, as we've suggested. If you know about
   for loops already, you can also add code here to display the keys using
   a loop, but we will get to loops next week...**

4. Under the relevant comment, add a line that prints out the values of
   the dictionary, then run the program again.

5. Under the relevant comment, add a line that prints out all the key-value
   pairs of the dictionary, then run the program again.

6. Add some code that will delete an entry from the dictionary, followed by
   a print statement that prints the dictionary. Run the program again to
   check that the relevant key-value pair has been removed.

   **Note: we've not covered key-value removal on the slides, so you will
   need to do your own research to discover how to do this!**
