# Task 6

In `task6.py`, create a dictionary to store details of your favourite music.

Each key of this dictionary should be the name of a favourite band or solo
artist. Each value should be a list of the names of albums released by
that band or solo artist.

When you've created a suitable dictionary, use Python's 'pretty print'
function, [`pprint()`][pp], to print out the dictionary.

Then experiment with accessing data in this data structure. For example,
add a line to your program that prints out the name of the first album
associated with a specific artist. Try doing this with a single line of code.

## Additional Work

1. Try making your data structure a bit more complex.

   For example, instead of storing just the names of favourite albums, store
   album name and year of release.

   Think carefully about what would be the most appropriate way of doing this.
   Then implement it and try running the program again.

2. If you already know Python...

   How would you go about counting the total number of albums in this music
   database? Add some code to `task6.py` that will perform this task.
