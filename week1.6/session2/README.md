# Week 1.6, Session 2

`image.py` defines an `Image` class to represent greyscale images. The design
and features of this class will be discussed at the start of the session.

The `images` directory contains various PGM images that you can use to
experiment with the `Image` class.

The `projects` directory contains various subdirectories, each containing
suggestions for projects you can work on during the session. Please see
the README.md files in those subdirectories for further details.
