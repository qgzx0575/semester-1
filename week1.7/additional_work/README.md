## Explore the `unittest` Framework

Last week, we covered object-oriented inheritance in Python. Here, you will apply that concept using Python's built-in `unittest` library, a framework used
to automate tests and manage shared setup/shutdown code.

In this framework:

- A test case is created by subclassing `unittest.TestCase`.

- Individual test steps are defined using methods that must start with the prefix `test` (e.g., `test_addition`).



1. Navigating to the official [Python unittest documentation](https://docs.python.org/3/library/unittest.html) and look at the "Basic example" section.

2. Take the test cases you wrote for Task 2 and rewrite them using this framework.
